# ইলিয়টগঞ্জ হাজী রহমত উল্লাহ জামিরিয়া মাদ্রাসা (EHRJ)
## মাল্টি-রোল ফ্ল্যাটার অ্যাপ্লিকেশন সেটআপ ও ব্যবহার নির্দেশিকা (বাংলা)

এই নির্দেশিকাটি ইলিয়টগঞ্জ হাজী রহমত উল্লাহ জামিরিয়া মাদ্রাসার শিক্ষক, শিক্ষার্থী, অভিভাবক, হিসাবরক্ষক ও অ্যাডমিনদের জন্য তৈরি করা ফ্ল্যাটার অ্যাপ্লিকেশনটি চালানো এবং রক্ষণাবেক্ষণের পূর্ণ বিবরণ প্রদান করে।

---

## ১. প্রকল্পের ভূমিকা ও মূল বৈশিষ্ট্য

- **প্রকল্পের নাম:** EHRJ Madrasha Multi-Role Flutter App
- **ফোল্ডার অবস্থান:** `ehrj_flutter_app/`
- **সমর্থিত প্ল্যাটফর্ম:** অ্যান্ড্রয়েড (Android), ওয়েব (Flutter Web / PWA), উইন্ডোজ ডেস্কটপ (Windows Desktop)
- **প্রাথমিক ভাষা:** বাংলা (Bangla)
- **ব্যাকএন্ড ইন্টিগ্রেশন:** বিদ্যমান Next.js ERP (`http://localhost:3000`)
- **প্রধান সুবিধাসমূহ:**
  1. **অফলাইন-ফার্স্ট হাজিরা ব্যবস্থা:** ইন্টারনেট না থাকলেও শিক্ষক হাজিরা গ্রহণ করতে পারবেন এবং ড্রাফট সেভ রাখতে পারবেন। ইন্টারনেট সংযোগ ফিরলে এক ক্লিকে সার্ভারের সাথে সিঙ্ক হবে।
  2. **মাল্টি-রোল ভিত্তিক ড্যাশবোর্ড:** অ্যাডমিন, শিক্ষক, শিক্ষার্থী, অভিভাবক ও হিসাবরক্ষকদের জন্য স্বতন্ত্র অভিজ্ঞতা।
  3. **অভিভাবক পোর্টাল:** একাধিক সন্তানের ফলাফল, হাজিরা ও বকেয়া ফি যাচাই।
  4. **পাবলিক পোর্টাল:** সাধারণ দর্শনার্থীদের জন্য মাদ্রাসার পরিচিতি, নোটিশ ও নতুন শিক্ষার্থী ভর্তি আবেদন।

## ৩. ব্যাকএন্ড সার্ভার চালু করা

ফ্ল্যাটার অ্যাপের সাথে তথ্য আদান-প্রদান নিশ্চিত করতে মূল Next.js সার্ভার চালু থাকতে হবে:

```bash
# মূল রিপোজিটরি ফোল্ডারে টার্মিনাল খুলুন:
cd "d:\Eliotgonj Hazi Rohmatollah Jamiria Madrasha Web Aplication"

# ব্যাকএন্ড সার্ভার চালু করুন (পোর্ট ৩০০০):
npm run start
# অথবা ডেভেলপমেন্ট মোডে:
npm run dev
```

সার্ভার চালু হলে ব্রাউজারে `http://localhost:3000/api/health` এ ভিজিট করে নিশ্চিত হোন যে স্ট্যাটাস `ok` আসছে।

## ৪. ফ্ল্যাটার অ্যাপ ডিপেন্ডেন্সি ইনস্টল ও রান করা

### ৪.১ ডিপেন্ডেন্সি ডাউনলোড
```bash
cd "d:\Eliotgonj Hazi Rohmatollah Jamiria Madrasha Web Aplication\ehrj_flutter_app"
flutter pub get
```

### ৪.২ কোড কোয়ালিটি ও টেস্ট পরীক্ষা
```bash
# স্ট্যাটিক অ্যানালাইসিস
flutter analyze

# স্বয়ংক্রিয় ইউনিট ও উইজেট টেস্ট
flutter test
```

### ৪.৩ ওয়েব ব্রাউজারে রান করা
```bash
flutter run -d chrome
```

### ৪.৪ উইন্ডোজ ডেস্কটপ মোডে রান করা
```bash
flutter run -d windows
```

### ৪.৫ প্রোডাকশন ওয়েব বিল্ড তৈরি
```bash
flutter build web --release
```
বিল্ড ফাইলগুলো `ehrj_flutter_app/build/web/` ফোল্ডারে জমা হবে, যা যেকোনো ওয়েব সার্ভারে সরাসরি ডেপ্লয় করা যাবে।

## ৬. অফলাইন হাজিরা ও ড্রাফট সিঙ্ক কার্যপদ্ধতি

১. শিক্ষক লগইন করার পর স্বয়ংক্রিয়ভাবে তার নির্ধারিত জামাত ও শাখার শিক্ষার্থী তালিকা লোকাল স্টোরেজে ক্যাশ হয়ে যায়।
২. ইন্টারনেটের অনুপস্থিতিতেও হাজিরা স্ক্রিনে উপস্থিত (P), অনুপস্থিত (A) ও ছুটি (L) চিহ্নিত করা যাবে।
৩. **"ড্রাফট সংরক্ষণ"** বাটনে চাপ দিলে হাজিরা রেকর্ডটি ফোনের লোকাল মেমোরিতে নিরাপদে সংরক্ষিত হবে। স্ক্রিনের উপরে হলুদ নোটিফিকেশনে পেন্ডিং সিঙ্কের সংখ্যা দেখাবে।
৪. ইন্টারনেট সংযোগ সক্রিয় হলে **"সিঙ্ক করুন"** বাটনে চাপ দিলে সমস্ত ড্রাফট স্বয়ংক্রিয়ভাবে মূল Next.js ডাটাবেজে যুক্ত হবে এবং স্ট্যাটাস সবুজ 'সিঙ্কড' এ রূপান্তরিত হবে।

## ৭. সমস্যা সমাধান (Troubleshooting)

1. **"সার্ভারের সাথে সংযোগ স্থাপন করা যায়নি" ত্রুটি:**
   - নিশ্চিত হোন ব্যাকএন্ড সার্ভার `http://localhost:3000` এ সচল রয়েছে।
   - অ্যান্ড্রয়েড ফিজিক্যাল ডিভাইসে রান করলে `AppConfig.apiBaseUrl`-এ কম্পিউটারের লোকাল আইপি (যেমন: `http://192.168.1.X:3000`) ব্যবহার করুন।
2. **লগইন সেশন মেয়াদোত্তীর্ণ:**
   - লগআউট করে পুনরায় সঠিক রোল ও পাসওয়ার্ড দিয়ে লগইন করুন।
3. **ফ্ল্যাটার বিল্ড ফেইল:**
   - `flutter clean` দিয়ে ক্যাশ পরিষ্কার করে আবার `flutter pub get` চালান।
